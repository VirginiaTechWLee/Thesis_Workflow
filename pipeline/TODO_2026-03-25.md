## Key Design Decisions

### 1. FEM-agnostic generator
The HEEDS study generator must be FEM-agnostic. When a new FEM is dropped in (not just the beam), the script reads its Bush.blk and generates the correct HEEDS project automatically.

### 2. Workflow architecture (decided 2026-03-25)
- **One YAML workflow, not four.** Studies A/B/C/D are dropdown options in `heeds_workflow3.yml`.
- **Workflow = single entry point (no GUI).** User picks study type → workflow calls `generate_heeds_study.py` → runs the generated `.heeds` file. No pre-committed `.heeds` files needed.
- **Option 2 (full pipeline):** Generate + execute in one workflow run. More robust, deterministic, less manual.
- Keep legacy projects (bolt3_sweep, quick_test) as dropdown options so nothing breaks.
